# Diplom_2
Были протестированы ручки для создания пользователя, создания заказа и входа в учетную запись 

test_login.py проверяет ручку входа в учетную запись. Позитивный сценарий: существующий пользователь может авторизироваться. Негативные сценарии: существующий пользователь не может войти в свою учетную запись, неверно указав email или пароль.

test_create_user.py проверяет ручку создания пользователя. Позитивный сценарий: пользователя можно создать, указав валидные email, пароль и имя. Негативные сценарии: нельзя создать пользователя, который уже зарегистрирован; нельзя создать пользователя, не заполнив одно из обязательных полей (email, password, name).

test_create_order.py проверяет ручку создания заказа. Позитивные сценарии: заказ может создать авторизированный пользователь, заказ может создать неавторизированный пользователь, можно создать заказ с ингредиентами. Негативные сценарии: нельзя создать заказ без ингредиентов, нельзя создать заказ с неверным хешем ингредиентов. 

Для создания тестов были использованы фикстуры и вспомогательные методы:

- conftest.py содержит в себе фикстуры для создания уникальных пользователей и для регистрации и удаления пользователей.
- base_methods.py содержит в себе методы на отправление запросов для регистрации пользователя, создания пользователя, входа в учетную запись, удаление пользователя по токену, удаления пользователя по email и паролю, создания заказа.
- helpers.py соержит в себе методы для генерации рандомных email, password и name.

Для генерации отчета был использован фреймворк allure.
